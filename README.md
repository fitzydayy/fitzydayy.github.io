# FitzyDayy Website V1

Static website for GitHub Pages.

## Files
- `index.html` — homepage and layout
- `styles.css` — visual design and responsive styles
- `data.js` — OOTD/product data
- `script.js` — search, filters and look detail modal

## Add a new OOTD
Open `data.js`, duplicate one object inside `LOOKS`, then change:
- `code`
- `title`
- `category`
- `mood`
- `colors`
- `description`
- `items`
- each item's `url` to your affiliate link

## Important
The sample shop links are currently `#`. Replace them with your real affiliate URLs before publishing.
